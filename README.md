# 番组口袋 · Bangumi Pocket

为手机重新设计的 Bangumi 非官方 Android 客户端。发现感兴趣的作品、记录观看进度，也看看好友最近在追什么。

[下载最新版](https://github.com/Wepdekr/bangumi-pocket/releases/latest) · [版本变更日志](CHANGELOG.md) · [反馈问题与建议](https://github.com/Wepdekr/bangumi-pocket/issues)

## 下载与安装

支持 **Android 7.0 及以上**。

1. 打开[最新版本页面](https://github.com/Wepdekr/bangumi-pocket/releases/latest)。
2. 展开 **Assets**，下载名称为 `bangumi-pocket-版本号.apk` 的文件。不要选择 `Source code`。
3. 打开下载好的安装包，按手机提示安装。若提示安装权限，请允许用于下载的浏览器安装应用。

已有旧版时可以直接覆盖安装，保留账号与收藏。[历史版本](https://github.com/Wepdekr/bangumi-pocket/releases)也可随时下载。

## 可以做什么

- **发现作品**：浏览动画、书籍、游戏、音乐和三次元作品，查看排行，搜索中日文名称。
- **查看放送**：按星期查看 Bangumi 标注的放送安排。
- **了解作品**：阅读简介、评分、章节、角色与声优、短评和长评摘要；从关联作品继续浏览前传、续集等内容。
- **管理收藏**：记录想看、在看、看过、搁置和抛弃，填写评分与短评。书籍、音乐和游戏使用对应的读、听、玩状态。
- **记录进度**：逐集勾选，或用「看到这里」一次标记此前的正篇章节。
- **关注好友**：查看自己与好友的动态，在支持互动的动态下发表情、查看互动人数与参与者。

内容与账号记录来自 [Bangumi](https://bgm.tv)。本 App 不提供视频播放；长评全文、讨论及部分社区内容会打开 Bangumi 原站阅读。

## 连接 Bangumi 账号

不连接账号也可以浏览作品、记录本机收藏。需要跨设备同步或查看好友动态时，再连接账号即可。

1. 打开底部「收藏」，点击「前往 Bangumi 获取个人令牌」。
2. 在 [Bangumi 官方页面](https://next.bgm.tv/demo/access-token)登录并生成个人访问令牌。
3. 回到 App，将令牌粘贴到「个人访问令牌」，点击「连接并同步」。

目前需要复制令牌，暂不支持在 App 中直接输入账号密码登录。令牌在 Android 端加密保存，App 不收集你的 Bangumi 密码。

连接后，收藏、评分、短评和章节进度会同步到账号。断网时修改先保存在本机，联网后可重试，也可以在「收藏」页点击「立即同步」。令牌过期时，点击「更新授权」换入新令牌。

原有本机片单不会自动上传。需要合并时，点击「导入本机片单」并确认；账号中已有的收藏状态、评价、标签和私密设置会保留。退出账号后可继续使用本机片单，未同步修改仍归原账号保存。

## 章节进度与评价

章节右侧的圆形勾选按钮同时表示观看和放送状态：

| 样式 | 含义 |
| --- | --- |
| 粉色空心 | 已放送，尚未看过；已完结作品的未看章节也使用此样式 |
| 灰色空心 | 尚未放送，或放送日期待定 |
| 粉色实心 | 已看过 |

放送状态依据 Bangumi 标注日期和手机当天日期判断，不表示具体播出时间。

「看到这里」会标记当前集及之前的正篇章节，保留后续已经看过的记录，并按累计进度生成动态。

选择「看过」「搁置」「抛弃」，或完成全部正篇章节时，会打开评分与短评弹窗。可以保存评价，也可以跳过并保留已有评价；之后仍可在详情页「我的收藏」中修改。

## 更新应用

在「收藏」页的「应用更新」中点击「检查更新」，即可查看新版说明并在 App 内下载。下载完成后会打开系统安装界面，按提示覆盖安装即可；首次使用时可能需要允许番组口袋安装应用。

App 启动时也会检查更新：补丁更新不主动弹窗，次版本更新可选择安装，主版本更新需安装后继续使用。手动检查可以发现所有新版本。

如果下载失败，可以重试，或前往 [GitHub 版本页面](https://github.com/Wepdekr/bangumi-pocket/releases/latest)下载安装包。

## 常见问题

**同步失败会丢失修改吗？**

未成功提交的修改会保留在本机，恢复网络或更新授权后可重试。请留意「收藏」页的同步提示。

**怎样删除账号里的收藏？**

在作品详情点击「在 Bangumi 管理收藏」，到原站删除后，回 App 点击「立即同步」。

**卸载后还能找回记录吗？**

已同步到 Bangumi 的记录可在重新连接账号后恢复。本机收藏及尚未同步的修改会随卸载或清除应用数据而删除。

**怎样反馈问题？**

请在 [Issues](https://github.com/Wepdekr/bangumi-pocket/issues) 提供 App 版本、手机型号、复现步骤和相关截图，方便定位。请勿附上个人令牌或密码。
